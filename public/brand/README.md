# Techno Solutions brand assets

The files in this folder are derived only from the logo reference supplied with
this project update. No external logo or font was downloaded.

- `techno-solutions-reference.png` — the supplied official reference on white.
- `techno-solutions-logo-dark.png` — transparent reference-colour wordmark for
  light surfaces (`#3c424e` with the original `#5ad8c5` accent).
- `techno-solutions-logo-light.png` — transparent high-contrast wordmark for
  dark header/footer surfaces; its geometry is identical to the reference.

The source package did not include an original SVG, EPS, AI file or licensed
font. The supplied raster artwork is therefore retained as the geometry source
instead of approximating the custom letterforms with a different typeface.
