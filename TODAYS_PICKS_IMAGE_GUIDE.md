# Today’s Picks — Gemini Image Guide

Place every final image in:

```text
public/images/todays-picks/
```

The interface already reserves each image area and shows a stable placeholder until the matching `.webp` file is added. Do not include product names, prices, labels, badges, buttons, or watermarks inside generated images; all essential content is rendered as accessible HTML.

## Shared production rules

- Format: WebP
- Color space: sRGB
- Minimum size: 1600 × 1200 px for the main spotlight source
- Preferred aspect ratio: 4:3
- Product occupancy: approximately 80–88% of the canvas
- Keep important product details inside a 6% safe area
- Use consistent premium studio lighting across the collection
- Prefer transparent backgrounds because the section creates its own product-specific environment in CSS
- Avoid large baked-in transparent or white margins
- No text, logos, prices, badges, CTA labels, borders, or watermarks
